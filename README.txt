TZWorkQuint Suite (Version 3.0.0)
Brand: TZLabs (https://tzlabs.in)
Target Platform: Windows x86_64

Included Applications:
- TZWorkQuint (Suite Launcher Hub): bin\tz-workquint.exe
- TZ CellForge (Spreadsheet): bin\tz-cellforge.exe
- TZ Wordloom (Word Processor): bin\tz-wordloom.exe
- TZ PDFlex (PDF Editor & Markup): bin\tz-pdflex.exe
- TZ Draftline (2D CAD Drafting): bin\tz-draftline.exe
- TZ SlideSpark (Slide Presentations): bin\tz-slidespark.exe

Offline Documentation:
- docs\user-guide\index.html

Usage:
This is the standalone portable release. All applications can be launched directly
from the bin\ folder without installation.

For system installation with Start Menu shortcuts and automatic integration,
run the Windows setup installer: TZWorkQuint-3.0.0-Setup.exe.
