Quick Start Guide

Get up and running with TZWorkQuint in less than two minutes.

Launching Applications

You can launch any of the five suite editors either directly from the Start Menu / Desktop shortcuts, or through the TZWorkQuint Suite Hub (tz-workquint.exe).

Direct Command Line Launchers
# Launch individual native applications directly:
tz-cellforge.exe [filename.xlsx]
tz-wordloom.exe [document.docx]
tz-pdflex.exe [document.pdf]
tz-draftline.exe [drawing.dxf]
tz-slidespark.exe [presentation.pptx]

# Or launch the unified launcher hub:
tz-workquint.exe

Creating Your First Document

  1. Open TZ CellForge. By default, an empty spreadsheet opens ready for input.
  2. Enter numerical values into cells B6:D6 and enter the formula =SUM(B6:D6) into E6.
  3. Press Ctrl+S to save the workbook as an Excel-compatible .xlsx file.
