TZ Assistant & AI Gateway Setup

TZWorkQuint features a modular AI architecture designed around local-first privacy, rigorous secret redacting, and transactional document modifications across all five editors.

Supported Provider Connections

  • TZ AI Gateway (Built-in / OpenAI-compatible): Connect using Local (http://localhost:3001/v1) or Remote (https://gateway.tzlabs.in/v1) modes, or configure any OpenAI-compatible API endpoint with optional bearer token. Features automatic Test Connection and live model discovery.
  • Google Gemini: Connect with Gemini API key to access live Gemini models through official model discovery.
  • Anthropic Claude: Connect with masked Claude API key to access Claude 3.5 Sonnet.
  • Custom OpenAI-Compatible Gateways: Configure custom base URLs with bearer tokens.

Live Model Discovery & Capabilities

When connecting to an AI provider:

  • The connection defaults to Choose a model until a valid model is explicitly selected.
  • Clicking [🔄 Refresh] queries the provider's list_models API dynamically and populates the model picker with verified chat and tool-capable models.
  • Discovered models are cached per-connection with a last-refreshed timestamp. If an endpoint is offline or credentials expire, cached models remain available with clear status badges, and your prompt draft is always preserved.
  • API keys and authentication bearer tokens are strictly masked (••••••••) in the UI and never leaked to logs, diagnostics, or exported files.

Document Context Scoping & Workflow Parity

External AI services only receive the explicit context you choose:

  • TZ CellForge: Propose formula revisions, mathematical projections, and multi-cell edits with visual diffs.
  • TZ Wordloom: Propose passage rewrites and document text improvements with before/after comparisons.
  • TZ PDFlex: Propose annotations and highlight comments on selected PDF text.
  • TZ Draftline: Propose precise CAD drawing edits and geometric entities.
  • TZ SlideSpark: Propose slide deck text revisions and layout enhancements.

Proposed modifications are previewed before applying, and all applied changes are fully reversible via Undo (Ctrl+Z).
